# Web Game

A static collection of 14 browser games. Open `index.html` through a local web server or publish the repository with GitHub Pages.

Each game keeps its own interface and controls. The site does not add shared timers, difficulty rules, sound, or game overlays.

To preview locally from the repository root:

```powershell
py -m http.server 4173
```

Then open `http://localhost:4173/`.
