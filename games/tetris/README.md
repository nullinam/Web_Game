# Tetris

The game is based on [ironman-29/tetris-game](https://github.com/ironman-29/tetris-game), with the repository's desktop game and controls retained.

## Controls

- Left / Right: move
- Up: rotate
- Down: soft drop
- Space: hard drop
- P: pause

The alternate mobile game pages were removed so the website presents one Tetris version.
