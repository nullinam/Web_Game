# Chess against the computer

This game uses the HTML/CSS/JavaScript chess rules and interface from [Harshv2608/Chess_game](https://github.com/Harshv2608/Chess_game), with an added Black AI opponent and four difficulty levels. White is controlled by the player.

The source README states that the project is available under the MIT License. The game interface and logic have been adapted for this site.

## Controls

Select one of your white pieces, then select a highlighted destination. Choose a difficulty before or during a new game. Use Undo turn to take back the last turn.
