    manual.exe — site guide

    Brand and home

    The code mark and lowkey.exe logo return you to the top. The tagline introduces the arcade and the Enter Arcade button jumps to the complete game library.

    Theme switch

    Click the glowing theme button to cycle through ten saved themes. Your choice is remembered on this device. Naruto, One Piece, Bleach, Void, and space themes change the home backdrop and accents; their special animations stay on the home page.

    Game library cards

    Each card shows the category, miniature game scene, short description, filename, and Run action. The Local tag means the game files are part of this website; Offline means no online account is needed. Choose a card to open its game.

    Separate game tabs

    Choose Run to open the game in a new browser tab. Each game keeps its own original screen and controls. Close that tab when you want to return to the arcade.

    Session panels

    Now Playing is an animated retro status screen. You Again lists up to five recently selected games. Still There changes its message after a period without input.

    Command line

    Click the prompt and type help, games, random, theme, clear, about, whoami, or sudo chill, then press Enter. Press / anywhere outside another text field to focus the prompt. The random.exe button opens one game from the library.

    Settings

    The gear opens the local settings card. Atmosphere effects can be switched off. Your theme and effects preference are saved in this browser.

    Offline storage and play

    Recent games and interface preferences are stored in browser storage. The games are files served by this website and do not require an account. Browser storage can be cleared from browser settings.

    Repository

    This is the lowkey.exe browser arcade: a static website with locally hosted games, separate game tabs, theme options, recent-game tracking, and no required account.

    Project owner

    You’re the person shaping this game collection. The site doesn’t publish personal profile details, so this card only describes what is visible in the project.

    How it runs

    The home page and game files live in one repository and can be hosted as a static site. Most play state is handled in your browser.
